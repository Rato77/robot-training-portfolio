# robot‑training‑portfolio
首届特种机器人六周开源复现挑战赛
> 赛道B：永磁吸附爬壁机器人｜控制与实验主责：Rato77

本仓库是个人实训作品集，用于留存本人全部可核验工程产出：单元测试代码、安全审查文档、每周工作记录、实验日志。
评审可通过本仓库查看个人完成证据；硬件实物证据待物料采购到货后补充归档。

## 🧑‍💻 岗位职责（控制与实验主责）
1. ESP32单片机程序编写、电机驱动单元测试
2. 软件安全逻辑：上电默认停机、速度限幅、失联停机逻辑开发
3. G0安全准入、强磁相关安全文档编写
4. 数据采集脚本、实验CSV数据、绘图处理
5. 后期重复性实验测试记录

## 🛠️ 开发环境与工具清单
- 编辑器：VS Code
- 版本控制：Git + GitHub
- 嵌入式：Arduino‑IDE（ESP32支持包）
- 数据分析：Python3.10（pandas、matplotlib，后期实验出图）
- 图表绘制：Draw.io
- 文档：Markdown
