# robot‑training‑portfolio
首届特种机器人六周开源复现挑战赛
> 赛道B：永磁吸附爬壁机器人｜控制与实验主责：Rato77

本仓库是个人实训作品集，用于留存本人全部可核验工程产出：单元测试代码、安全审查文档、每周工作记录、实验日志。

## 🧑‍💻 岗位职责（控制与实验主责）
1. ESP32单片机程序编写、电机驱动单元测试
2. 软件安全逻辑开发：上电默认停机、速度限幅、通信失联停机
3. G0安全准入、强磁授权审查文档编写
4. 单元测试、数据记录、故障复盘、周报整理归档
5. 与结构主责对接机械方案，提供电控接口需求

## 🛠️ 开发环境与工具清单
- 编辑器：VS Code
- 版本控制：Git + GitHub
- 嵌入式开发：Arduino‑ESP32
- 脚本处理：Python3.10（后期数据分析、绘图）
- 图表绘制：Draw.io（系统框图、电源树、风险图）
- 文档格式：Markdown
- 仿真（选修）：Webots
