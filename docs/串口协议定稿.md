# 串口协议定稿（帧格式 / 校验 / 采样率）

> 组号：第七组·赛道 B 永磁吸附爬壁机器人；ESP32-WROOM-32 ↔ 上位机（Python）。  

## 1 物理层与速率

| 项目  | 定稿值                               | 说明                        |
| --- | --------------------------------- | ------------------------- |
| 接口  | ESP32 USB-CDC（虚拟串口），3.3V TTL 电平   | 与系统说明"串口调试"一致             |
| 波特率 | 115200 bit/s，8 数据位、无校验、1 停止位（8N1） | 足够承载 20 Hz 遥测，误码率低        |
| 流控  | 无（XON/XOFF、RTS/CTS 均关闭）           | 上位机按帧解析，不依赖流控             |
| 帧边界 | 以 `\r\n` 结束；单帧 ≤ 128 字节（含换行）      | 接收缓冲上限 128，超长丢弃并计 CRC/长度错 |

带宽核算：遥测帧约 70 字符，70 B × 10 bit × 20 Hz ≈ **14 kbit/s**，占 115200 的约 12%，余量充足。

## 2 帧格式

### 2.1 下行：上位机 → ESP32（指令帧，心跳 10 Hz）

```
!C,<seq>,<cmd>,<pwm_l>,<pwm_r>,<t_ms>*<CRC2>\r\n
```

| 字段              | 含义                | 取值                                                         |
| --------------- | ----------------- | ---------------------------------------------------------- |
| `!C`            | 帧头 + 类型           | 固定                                                         |
| `seq`           | 指令序号（uint32）      | 仅接受 `seq > 上次接受序号` 的新帧，防重复/乱序                              |
| `cmd`           | 命令                | `0`=STOP（立即停机），`1`=RUN（按 PWM 运行），`2`=CLR_FAULT（仅清故障锁存，不驱动） |
| `pwm_l`,`pwm_r` | 左右轮占空比            | 有符号整数 −255…255；正=前进，负=后退；固件再按 `PWM_LIMIT=179`（70%）限幅       |
| `t_ms`          | 上位机时间戳（uint32，ms） | 用于测链路时延，不参与停机判定                                            |
| `CRC2`          | 2 位十六进制校验         | 见第 3 节                                                     |

示例（已计算校验）：

```
!C,1,1,100,100,1000*26\r\n     ← 序号1，RUN，左右各100
!C,2,0,0,0,1100*A4\r\n         ← 序号2，STOP
```

**心跳规则**：即使静止也必须每 **100 ms（10 Hz）** 发送一次 `cmd=0, pwm=0` 的心跳帧。连续 **5 帧**（500 ms）未收到有效帧即判失联（见任务⑤）。

### 2.2 上行：ESP32 → 上位机（遥测帧，20 Hz）

```
#T,<seq>,<t_us>,<cnt_l>,<cnt_r>,<pwm_l>,<pwm_r>,<state>,<flags>*<CRC2>\r\n
```

| 字段              | 含义                  | 取值                                                 |
| --------------- | ------------------- | -------------------------------------------------- |
| `#T`            | 帧头 + 类型             | 固定                                                 |
| `seq`           | 上行序号（uint32）        | 每发一帧 +1，掉电归零                                       |
| `t_us`          | micros() 时间戳        | 用于计算实际采样间隔与抖动                                      |
| `cnt_l`,`cnt_r` | 左右编码器累计四倍频计数（int32） | 上电 zero，用于里程/速度                                    |
| `pwm_l`,`pwm_r` | 实际施加的 PWM           | −179…179（已限幅）                                      |
| `state`         | 状态机                 | `0`=STOP，`1`=RUN，`2`=FAULT                         |
| `flags`         | 故障位（bitmask）        | bit0=通信超时，bit1=超速回收，bit2=急停输入，bit3=堵转，bit4=CRC/长度错 |
| `CRC2`          | 2 位十六进制校验           | 见第 3 节                                             |

示例：

```
#T,1,123456,0,0,0,0,0,0*9E\r\n
#T,2,173456,12,-12,0,0,1,0*47\r\n
```

## 3 校验

**CRC-8（多项式 0x07，初值 0x00，无反射、无异或）**，作用范围为帧头标志之后、`*` 之前的所有字符（即指令帧对 `C,...` 计算，遥测帧对 `T,...` 计算）。比异或校验更能检出突发错误，且 8 位实现成本极低。

C 实现（固件与 Python 上位机必须一致）：

```c
uint8_t crc8(const char *s) {
  uint8_t crc = 0x00;
  while (*s) {
    crc ^= (uint8_t)(*s++);
    for (int i = 0; i < 8; i++)
      crc = (crc & 0x80) ? (uint8_t)((crc << 1) ^ 0x07) : (uint8_t)(crc << 1);
  }
  return crc;
}
```

Python 校验（上位机落 CSV 前必须验证）：

```python
def crc8(s: str) -> int:
    crc = 0
    for b in s.encode("ascii"):
        crc ^= b
        for _ in range(8):
            crc = ((crc << 1) ^ 0x07) & 0xFF if crc & 0x80 else (crc << 1) & 0xFF
    return crc
```

校验失败处理：**丢弃该帧**、累计 CRC 错误计数（遥测 flags bit4 上报），不改变当前 PWM；通讯看门狗继续计时。

## 4 采样率与时序预算

| 任务                  | 周期                       | 依据/理由                     |
| ------------------- | ------------------------ | ------------------------- |
| 编码器 A/B 计数          | 边沿触发中断（硬件 GPIO4/5/18/19） | 不轮询，避免丢失脉冲；四倍频            |
| 控制环（限速、失联判定、PWM 输出） | 10 ms（100 Hz）            | 失联后可在 10 ms 内 PWM 归零      |
| 上位机心跳               | 100 ms（10 Hz）            | 任务⑤：500 ms = 5 个心跳周期      |
| 遥测上行                | 50 ms（20 Hz）             | 满足实验 E1–E3 记录需求，带宽占用 ~12% |
| 堵转检测（可选）            | 300 ms 窗口                | 有 PWM 但计数增量≈0 时置故障        |

时序约束：`lastCmdMs` 在**通过 CRC + 序号检查**后才刷新；CRC 错帧不刷新看门狗。遥测发送不得阻塞控制环（用 `millis()` 非阻塞调度，禁止 `delay()`）。

## 5 与 CSV 的字段映射（供任务⑥使用）

上行遥测一帧即 CSV 一行实验原始数据：`t_us, cnt_l, cnt_r, pwm_l, pwm_r, state, flags`；实验专用列（气隙、拉脱力、电流、温升等）由上位机在采集界面补录，不塞进固件帧，保持协议精简。
