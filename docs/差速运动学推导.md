# 差速运动学推导（含数值例）

## 0 符号与取值来源

| 符号         | 含义             | 取值                    | 来源                                      |
| ---------- | -------------- | --------------------- | --------------------------------------- |
| `r`        | 驱动轮半径          | 0.0325 m（轮径 65 mm）    | 系统说明文档 §三、§七、§十                         |
| `L`        | 左右驱动轮接地点间距（轮距） | **暂取 0.12 m，W3 实测替换** | 车架宽 100 mm + 两侧轮厚；任务书 2.2 未给定           |

| `v_L, v_R` | 左右轮接地点线速度（m/s） | `v = r·ω`             | 推导                                      |
| `v`        | 车体前进速度（m/s）    | 两轮平均                  | 推导                                      |
| `ω`        | 车体角速度（rad/s）   | 两轮差/L                 | 推导                                      |

> 约束：`L` 是关键敏感参数，`ω ∝ 1/L`；轮距 10% 误差直接带来角速度 10% 误差，W3 装配后必须用卷尺/卡尺实测左右轮中心距并写进固件常量。

## 1 正运动学：轮速 → 车体速度

纯滚动、无侧滑假设下，左右轮接地点速度等于轮胎线速度：

```
v_L = r·ω_L ,   v_R = r·ω_R
车体纵向速度：  v = (v_L + v_R) / 2 = r(ω_L + ω_R) / 2
车体角速度：    ω = (v_R − v_L) / L = r(ω_R − ω_L) / L
转弯半径：      R = v / ω = L(v_L + v_R) / [2(v_R − v_L)]
```

由转速 rpm 换算：`ω_wheel = 2πn/60`，`v = r·2πn/60 = 0.003403 n`（m/s，r=0.0325）。

**数值例 1 — 双轮同速额定前进**：`n_L = n_R = 60 rpm`

```
ω_L = ω_R = 2π×60/60 = 6.283 rad/s
v_L = v_R = 6.283 × 0.0325 = 0.2042 m/s
v = 0.2042 m/s（20.4 cm/s），ω = 0，直线行驶
```

**数值例 2 — 差速右转**：`n_L = 45 rpm, n_R = 60 rpm`

```
v_L = 0.1532 m/s, v_R = 0.2042 m/s
v = (0.1532+0.2042)/2 = 0.1787 m/s
ω = (0.2042−0.1532)/0.12 = 0.4254 rad/s = 24.4°/s
R = 0.1787/0.4254 = 0.420 m（左转半径为正；此例为右转，ω 取负）
```

**数值例 3 — 原地转向**：`n_L = −30 rpm, n_R = +30 rpm`

```
v_L = −0.1021 m/s, v_R = +0.1021 m/s
v = 0，ω = 0.2042/0.12 = 1.702 rad/s = 97.5°/s，R = 0（绕车体中心自转）
```

## 2 逆运动学：期望 (v, ω) → 轮速

```
v_L = v − ωL/2 ,   v_R = v + ωL/2
n_L = v_L/(2πr)×60 ,  n_R = v_R/(2πr)×60
```

**数值例 4**：希望 `v = 0.15 m/s, ω = 0.5 rad/s`（L=0.12）

```
v_L = 0.15 − 0.5×0.12/2 = 0.120 m/s → n_L = 35.3 rpm → 占空比 ≈ 35.3/77 = 45.8%
v_R = 0.15 + 0.5×0.12/2 = 0.180 m/s → n_R = 52.9 rpm → 占空比 ≈ 68.7%
```

两轮占空比均低于 70% 限速上限，可行。若指令要求 `v > 0.183 m/s`（70% 占空比对应空载上限），固件应整体缩放两轮占空比而不是只钳位单轮，否则车会跑偏。

## 3 与编码器 / PWM 的接口

编码器输出轴每转计数 `N = 11 × 78 × 4 = 3432`（详见任务③）。由 Δcnt 求速度：

```
Δs_L = (cnt_L(t)−cnt_L(t−T)) × 2πr/N
v_L = Δs_L / T ,   v_R 同理，再代入第 1 节公式
```

取 `T = 50 ms` 时，1 个计数对应 1.19 mm/s 速度量化（见任务③）。

## 4 模型边界（答辩必须说明）

1. 纯滚动假设在磁吸附加大法向力、钢面有涂层或胎面磨损时不严格成立；打滑次数由实验 E3 记录。
2. 转向时外侧轮负载增加、内侧轮可能微滑，`L` 的有效值随姿态微变；本设计按固定 `L` 处理，误差由实测修正。
3. 电机空载 77 rpm 与额定 60 rpm 有 ±15% 供应商公差，开环占空比→转速映射必须用编码器闭环或标定曲线，不能照抄理论值。
4. 本推导适用于水平钢板；垂直工况未授权，不在此模型内。
