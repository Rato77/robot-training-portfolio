# 编码器分辨率与测速误差

## 1 编码器参数链（必须区分"电机轴"与"输出轴"）

| 层级      | 参数                       | 数值                  | 依据                                          |
| ------- | ------------------------ | ------------------- | ------------------------------------------- |
| 电机本体    | 编码器 A/B 相每转信号数           | **11 PPR（电机轴）**     | JGA25-370 带编码器供应商接线说明：黄/绿线"电机一转 11 个信号"     |
| 减速箱     | 减速比                      | **78:1**            | 12V 77 rpm 型号对应 i=78（供应商性能表；系统文档 §七 77 rpm） |
| 解码      | 四倍频（A、B 双边沿）             | ×4                  | 承接 01 号协议"边沿中断计数"                           |
| **输出轴** | 每转计数 `N = 11 × 78 × 4`   | **3432 counts/rev** | 计算                                          |
| 轮胎      | 周长 `C = 2πr = 2π×0.0325` | **0.204204 m**      | 系统文档轮径 65 mm                                |

> 供应商标称须实测复核：W2 用手转输出轴一整圈，读 `cnt` 增量，预期 ≈3432；若实物为 12 PPR 或 i=75，按实测值重算所有量。

## 2 分辨率

```
距离分辨率  Δs = C / N = 0.204204 / 3432 = 5.95×10⁻⁵ m = 0.0595 mm/count
角度分辨率  Δθ = 360° / 3432 = 0.105°/count（输出轴）
```

单个计数对应 0.06 mm 位移，分辨率远高于机械传动回差与轮胎打滑，因此**分辨率不是误差主要来源**。

## 3 测速方法：M 法（定时计数）

在固定窗口 `T` 内计数 `Δcnt`：

```
v = (Δcnt / N) × C / T
速度分辨率（1 count）：Δv = C/(N·T) = Δs/T
```

| 采样窗口 T    | 速度分辨率 Δv      | 额定 0.204 m/s 时相对量化 | 适用                     |
| --------- | ------------- | ------------------ | ---------------------- |
| 10 ms     | 5.95 mm/s     | 2.9%               | 控制环内部（任务①：100 Hz）      |
| **50 ms** | **1.19 mm/s** | **0.58%**          | **遥测/实验记录（任务①：20 Hz）** |
| 100 ms    | 0.595 mm/s    | 0.29%              | 低速稳态测量                 |

计数频率核对：额定 60 rpm 输出轴 → 3432 counts/s/轮，50 ms 窗口约 172 counts，远高于 1，M 法适用。

**低速补充**：当 `v < 0.02 m/s`（≈336 counts/s，约 3 ms/count）时 M 法窗口内计数太少，改用 T 法（测相邻边沿周期）或 M/T 混合法；代码里按计数阈值切换，避免速度读数跳变。

## 4 误差预算（额定工况 v≈0.204 m/s，T=50 ms）

| 误差源                | 量级            | 相对误差    | 说明 / 缓解                  |
| ------------------ | ------------- | ------- | ------------------------ |
| 计数量化（±1 count）     | ±1.19 mm/s    | ±0.58%  | 增大 T 可降，但延迟增加；50 ms 为折中  |
| 轮径误差（r 实测 ±0.3 mm） | —             | ±0.92%  | 用游标卡尺测胎面外径，多点取平均         |
| 采样定时器抖动（±1 ms）     | —             | ±2%（最坏） | 用硬件定时器调度，禁止 `delay()` 漂移 |
| 减速箱回差/齿隙           | 正反转切换约 1–2 个齿 | 换向瞬间显著  | 速度取滑动平均；里程在换向点标记         |
| 轮胎打滑               | 取决于 μ、气隙与推力   | 可达数 %   | 实验 E3 记录打滑次数，不把滑移当编码器误差  |
| A/B 相序接反           | 计数方向反         | 系统性     | 上电正转测试：cnt 必须递增，否则交换 A/B |

按均方根合成（不含打滑）：`√(0.58² + 0.92² + 0.2²) ≈ 1.1%`。**结论**：在 50 ms 窗口下，编码器测速的系统误差约 1%，满足 E3 行驶可靠性实验的量化需求；若系数要求 <0.5%，需把窗口扩到 100 ms 并把轮径测到 ±0.1 mm。

## 5 关键实现要点

1. GPIO4/5/18/19 用 `INPUT_PULLUP`，A/B 任一变化进入中断；用 2 位状态机解码四倍频，避免毛刺造成误计数。
2. 上位机落盘的是**累计计数**，速度由 Python 后处理计算；这样即使采样抖动也不会丢失原始脉冲信息（符合手册"保留原始脉冲记录"）。
3. 里程 `s = Δcnt × 0.0000595 m`；左右轮分别累计，转向时两轮里程不等属正常。
4. 通讯协议字段 `cnt_l/cnt_r` 为 int32，连续运行 10⁹ counts 约 59 km 才溢出，本实验无需处理回绕。
