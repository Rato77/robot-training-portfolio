# 实验方案 E1—E3（变量 / 重复 / CSV 列）

> 依据：小组任务书 2.3、4.3、附件 B；学生手册附件 D（D1 一次实验必须记录、D3 磁吸赛道字段）。  
> 通用规则：每档 **≥3 次重复**，全部原始行入 CSV（不许只挑成功的一次）；实验顺序随机化；记录固件 Commit、钢板材质/厚度/涂层、环境温度；任一异常（夹伤风险、磁体松脱、堵转、滑移、失联）立即停机并写异常记录。

## 1 实验设计总表

| 实验            | 目的 / 假设                        | 自变量（水平）                                                    | 因变量（单位）                                    | 控制不变                                       | 重复                | 停机条件                        |
| ------------- | ------------------------------ | ---------------------------------------------------------- | ------------------------------------------ | ------------------------------------------ | ----------------- | --------------------------- |
| **E1 气隙—拉脱力** | 气隙增大 → 法向拉脱力下降；存在"还能走"的临界气隙 g* | 气隙 **0.5 / 1 / 2 / 3 mm**（任务书四档；实测塞尺值入表）                   | 峰值拉脱力 F_pull（N）；断裂/脱落形态                    | 同一钢板、同一 16 片同向磁阵 + 轭铁、同一测力计、同一拉取方向与速率      | 每档 **3 次**        | 磁体移位/崩裂、夹伤风险、测力计超量程         |
| **E2 磁阵对比**   | 同向/交替排布、有/无轭铁改变拉脱力与转向阻力        | 排布 2 水平 × 轭铁 2 水平 = **4 组**；若第二组磁体未获批则降级为"同向阵列 × 有/无轭铁"2 组 | 拉脱力（N）、转向阻力矩（N·m）、整机质量（kg）                 | 气隙固定（建议 1 mm）、同一钢板与测力计、磁体数量与质量接近           | 每组 **3 次**        | 同 E1；装配力不可控时放弃交替阵列（任务书 2.4） |
| **E3 行驶可靠性**  | 连续运行下电流/温升/打滑是否随时间恶化           | 连续运行时间（**0 / 5 / 10 / 15 min** 分段记录）                       | 电流均值/峰值（A）、电机与驱动温升（℃）、打滑次数、实际里程（m）、速度误差（%） | 同一路面、同一速度指令（建议 v=0.10 m/s，占空比≈47%）、同一气隙与磁阵 | **3 轮**，每轮 15 min | 异常热/冒烟/异响、堵转、失联、异常滑移        |

## 2 CSV 列定义（落盘即原始证据，UTF-8，逗号分隔，首行表头）

### 2.1 公共列（三个实验都必须有）

| 列名                                                       | 单位/格式        | 说明                          |
| -------------------------------------------------------- | ------------ | --------------------------- |
| `exp_id`                                                 | 字符串          | `E1`/`E2`/`E3`              |
| `run_id`                                                 | 字符串          | 每次实验唯一编号，如 `E1-20261126-01` |
| `repeat_idx`                                             | 整数           | 1/2/3（同一条件下的重复序号）           |
| `timestamp_iso`                                          | ISO 8601     | 采样时刻                        |
| `operator` / `observer`                                  | 字符串          | 操作手 / 审查者（三人轮换，任务书 4.3）     |
| `firmware_commit`                                        | 字符串          | 固件 Git SHA，关联任务①协议版本        |
| `robot_version`                                          | 字符串          | 样机版本（磁阵/气隙配置）               |
| `mass_kg`                                                | kg           | 实测整机质量                      |
| `steel_grade` / `steel_thickness_mm` / `surface_coating` | — / mm / 字符串 | 钢板材质、厚度、涂层（手册 D1）           |
| `ambient_temp_C`                                         | ℃            | 环境温度                        |
| `notes`                                                  | 字符串          | 异常、停机、方法变更（如改用弹簧秤必须写明）      |

### 2.2 实验专有列

**E1**  
`gap_setting_mm`（垫片档位）, `gap_measured_mm`（塞尺实测）, `shim_stack_mm`（垫片叠厚）, `pull_force_N`（峰值）, `pull_rate_mm_s`（拉取速率）, `peak_hold_s`, `force_gauge_id`（测力计编号/量程）, `failure_mode`（脱附/磁体位移/其他）

**E2**  
`layout`（aligned / alternating）, `yoke`（0/1）, `gap_measured_mm`, `magnet_count`, `pull_force_N`, `yaw_torque_Nm`, `yaw_method`（转向阻力测量方法）, `mass_kg`, `failure_mode`

**E3**  
`elapsed_s`, `pwm_cmd_l` / `pwm_cmd_r`, `v_cmd_m_s`, `cnt_l` / `cnt_r`（来自任务①遥测）, `v_meas_l_m_s` / `v_meas_r_m_s`, `current_mean_A` / `current_peak_A`, `motor_temp_C` / `driver_temp_C`, `slip_events`, `comm_timeouts`, `estop_events`, `state` / `flags`（0/1/2；故障位）, `distance_m`

> E3 的 `cnt_l/cnt_r/state/flags` 直接来自任务①遥测帧 `#T,...`，无需人工转录；电流/温度由上位机或万用表补录到同一行。

## 3 数据处理与图表

1. 每条件计算 `mean ± SD`（n=3），E1 画 **F_pull–gap 曲线**（横轴实测气隙，纵轴拉脱力，带误差棒），标出 g*。
2. E2 画四组柱状对比图；若方案②未开展，按任务书 2.4 在"局限与下一步"写明"已评估、未开展、原因"。
3. E3 画电流/温度随时间曲线，记录所有异常时间点；打滑次数按 15 min 累计。
4. 所有图必须能由 `data/*.csv` 重新生成（脚本入 `tests/`，符合手册 4.4/11.1）。
