# 电气预算（电流分配、TB6612 余量）

## 1 供电架构（来自系统说明文档 P6–P7）

`12V 适配器（3A 限流）→ 5A 急停/总开关 → 12V 动力分配 → TB6612FNG 的 VM`；  
`12V → DC-DC 降压 → 5V → ESP32（板载 3.3V）→ TB6612 的 VCC(3.3V)`；各模块 **GND 共地**。

## 2 电流分配表

| 支路       | 器件 / 参数                           | 工作电压 | 典型电流         | 最坏（堵转/峰值）        | 折算 12V 典型电流              | 保护与依据                 |
| -------- | --------------------------------- | ---- | ------------ | ---------------- | ------------------------ | --------------------- |
| 左驱动轮     | JGA25-370-1260，78:1，12V 60–77 rpm | 12V  | 0.45 A（额定负载） | **1.3 A 堵转**     | 0.45 A                   | 供应商性能表；W2 实测堵转电流      |
| 右驱动轮     | 同上                                | 12V  | 0.45 A       | **1.3 A 堵转**     | 0.45 A                   | 同上                    |
| 驱动 IC 逻辑 | TB6612FNG 的 VCC                   | 3.3V | ≈0.02 A      | ≈0.03 A          | ≈0.005 A                 | 系统文档：VCC 接 ESP32 3.3V |

**合计（12V 侧）**

- 正常行驶：`0.45 + 0.45 + 0.15 ≈ 1.05 A` → 适配器 3 A 的 **35%**，余量 1.95 A。
- 双轮同时堵转（无防护）：`1.3×2 + 0.25 = 2.85 A` → 适配器额定的 **95%**，几乎满载，不可持续。
- 软件限幅 70% 后堵转：`(1.3×0.7)×2 + 0.25 = 2.07 A` → **69%**，可接受。

## 3 TB6612FNG 余量核算

数据手册（Toshiba）：`IOUT(ave) = 1.2 A/通道`，`IOUT(peak) = 3.2 A/通道（短脉冲）`，`VM ≤ 15 V（模块推荐 2.5–13.5 V）`，`VCC 2.7–5.5 V`，`R_on(高+低) ≈ 0.5 Ω`。

| 工况            | 单通道电流  | 对 1.2 A 平均额定         | 结论                    |
| ------------- | ------ | -------------------- | --------------------- |
| 额定 0.45 A     | 0.45 A | 余量 0.75 A（**62.5%**） | 充足                    |
| 供应商标称堵转 1.3 A | 1.3 A  | **超 0.1 A（8.3%）**    | 不允许持续；仅 3.2 A 峰值容短时浪涌 |
| 限幅 70% 堵转     | 0.91 A | 余量 0.29 A（24%）       | 安全，作为设计工作点            |

导通损耗估算：`P ≈ I²·R_on`，限幅堵转时 `0.91²×0.5 ≈ 0.41 W/通道`（双路 ≈0.83 W），SSOP-24 需铺铜散热；无散热时 1.2 A 连续将达 0.72 W/通道，热关断风险高。

## 4 强制措施（写进固件/接线，不是建议）

1. **PWM 上限 179/255（70%）**：由 `I_limit=1.0 A` 与电机内阻 `R_m≈12/1.3=9.23 Ω` 得 `D_max = I_limit·R_m/12 ≈ 77%`，取 70% 留余量。预估最高空载转速 `77×0.7=53.9 rpm`，对应车速 `0.183 m/s`。
2. **堵转检测**：有 PWM 且 300 ms 内计数增量≈0 → 立刻置 FAULT、PWM 归零（任务⑤代码已实现）。
3. **硬件急停不可省**：5A 自锁开关串联 12V 主回路；软件限幅是第二道防线。
4. **W2 实测堵转电流**：若实测 >1.3 A，按比例下调 PWM_LIMIT 或更换额定电流更高的驱动器（手册 B3："TB6612 仅限符合额定电流的电机"）。
5. **E3 记录温升**：连续运行实验同步记录驱动芯片与电机外壳温度；异常热立即停机。

## 5 结论

适配器 3 A 在限幅后余量 31%，TB6612 在额定工况余量 62.5%、堵转工况**无持续余量**。因此本系统必须按"限速 + 堵转检测 + 硬件急停"三重约束运行，禁止去掉限幅直接满占空比堵转测试。
